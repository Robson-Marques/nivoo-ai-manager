# 21st.dev MCP

1. Obtenha uma chave atual em https://21st.dev/mcp (chaves antigas Magic foram substituídas).
2. Conexões → Ferramentas das IAs (MCP) → Nova ferramenta → 21st.dev.
3. Endereço HTTP https://21st.dev/api/mcp, cabeçalho secreto x-api-key. Cole somente na configuração, nunca no chat.
4. Selecione os projetos de software desejados e salve. O preset começa com seleção explícita de projetos.
5. Use Testar para initialize e tools/list. Confirme search e get_component de acordo com a conta. O teste lista ferramentas, não compra nem gera componentes.
6. Em projeto autorizado com conector MCP compatível, peça criação de interface ou uso de biblioteca de componentes. O catálogo complementa a implementação local.

Acesso gratuito e limites de obtenção de código dependem da conta e podem mudar. Geração hospedada, desbloqueio pago e publicação exigem autorização específica. A Skill orienta o agente, mas o gerenciador MCP genérico não aplica allowlist por ferramenta nem bloqueio técnico de gastos externos. A conexão é opcional; sem chave, cota ou transporte, prossiga localmente quando possível. O Nivoo não instala a CLI legada nem troca provedor automaticamente. Claude/Codex e conectores Gemini que efetivamente recebem MCP usam os adaptadores existentes; NVIDIA, OpenRouter e Groq não têm esse transporte. A conectividade real precisa ser testada no servidor com credencial válida.
